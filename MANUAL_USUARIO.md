# Manual de Usuario - SendMessage

Esta guía explica cómo utilizar la aplicación para escribir y enviar un mensaje a otra pantalla.

---

### Paso 1: Escribir el mensaje
Al abrir la aplicación, pulsa sobre el cuadro de texto central donde dice *"Escriba aquí su mensaje..."* para desplegar el teclado e introduce el texto que deseas enviar.

---

### Paso 2: Enviar el mensaje
Una vez redactado el texto, pulsa el botón **"Enviar mensaje"** situado en la parte inferior de la pantalla.

---

### Paso 3: Comprobar el mensaje en la segunda pantalla
Tras pulsar el botón, la aplicación cambiará de pantalla automáticamente mostrando el mensaje que acabas de enviar para que puedas verificarlo.
